## 1. 产品概述

### 1.1 一句话定位

面向年轻女性的智能衣橱穿搭助手：**拍照上传 → AI 抠图分类 → 数字衣柜 → 每日穿搭推荐**，并延伸闲置管理与穿搭社区。

### 1.2 背景与问题

| # | 痛点         | 现状             | 后果                 |
| - | ---------- | -------------- | ------------------ |
| 1 | 早晨穿搭决策疲劳   | 凭记忆翻找试错        | 每天浪费 10+ 分钟，穿搭重复率高 |
| 2 | 衣物资产无数字化清单 | 买→忘→再买循环       | 重复购买与长期闲置并存        |
| 3 | 穿搭灵感无法落地   | 小红书收藏的是"别人的衣柜" | 灵感与自有单品脱节          |

### 1.3 目标用户

- 主：18–30 岁城市年轻女性，通勤/学生两大人群
- 特征：对穿搭有表达欲但缺乏方法或时间；社交媒体重度用户

### 1.4 产品目标（V1.0）

- 用户价值：3 秒内得到"今天穿什么"的可执行答案
- 业务验证：跑通「录入 → 推荐 → 采纳」核心闭环，验证 Aha 时刻假设（录入 ≥5 件后留存显著提升）

## 2. 需求范围与优先级

### P0（MVP，必须有）

| 模块    | 功能点                         | 说明                                        |
| ----- | --------------------------- | ----------------------------------------- |
| 账号    | 手机号验证码登录/自动注册               | 三方登录（微信/Apple）后置                          |
| 录入    | 拍照/相册上传，AI 自动抠图去背景          | 抠图失败可重拍；录入成本是全产品生死线                       |
| 录入    | AI 五维标签：品类/颜色/季节/风格/场合      | 标签可增删改，AI 推荐补充标签                          |
| 衣柜    | 双列网格浏览 + 分类 Tab + 搜索 + 排序筛选 | 搜索支持名称/颜色/标签                              |
| 衣柜    | 单品详情档案                      | 图片、标签、购买信息（选填）、穿着次数、常搭单品；编辑/标记闲置/删除（二次确认） |
| AI 搭配 | 场合（单选）×风格（多选）×天气（自动）生成搭配    | 可指定单品围绕搭配；可开关"避开闲置单品"                     |
| 搭配结果  | 适配度评分 + 搭配理由 + 单品清单         | 单品级"换一件"、整套"换一套看看"（方案 B/C）                |
| 搭配库   | 保存搭配、卡片流 + 穿搭日历双视图          | 日历点选某天联动当日穿搭                              |
| 首页    | 天气卡 + 今日推荐流 + 快捷入口 + 最近搭配   | 推荐流横滑，标注适配度                               |

### P1（第二个版本）

| 模块   | 功能点                                    | 说明          |
| ---- | -------------------------------------- | ----------- |
| 闲置管理 | 90 天未穿自动提醒（可开关）                        | 天然召回钩子      |
| 闲置管理 | 闲置统计：品类占比、90 天穿着频次、沉睡 TOP10、闲置估值       | ECharts 可视化 |
| 闲置管理 | 处理出口：挂二手 / 预约捐赠 / 暂不处理                 | 一键操作 + 结果反馈 |
| 社区   | 穿搭广场：推荐/关注/同城瀑布流，点赞互动                  | 内容源=真实衣柜搭配  |
| 社区   | 发布 OOTD：从搭配库选套 + AI 帮写文案 + 话题标签 + 同步日历 | 发布前校验已选搭配   |

### P2（规划）

- 风格偏好测试 → 个性化推荐权重
- 一衣多穿报告 / 单品利用率分析
- 虚拟试穿上身图生成
- 反向购物建议：只推荐"能激活 N 件闲置"的单品

## 3. 核心流程

### 3.1 主流程（衣物 → 穿搭）

```
拍照/相册 → AI抠图 → 五维标签(可改) → 存入衣柜
→ AI搭配(天气×场合×风格) → 适配度+理由 → 换一件/换一套
→ 保存搭配库 → (记录到穿搭日历 / 发布OOTD到广场)
```

### 3.2 辅助流程（衣橱新陈代谢）

```
90天未穿 → 闲置提醒 → 闲置统计(占比/频次/估值)
→ 挂二手 / 预约捐赠 / 继续沉睡
```

### 3.3 页面流程图

```
引导页 → 登录注册 → 首页
首页 ├→ 拍照录入 → 我的衣柜 → 衣物详情 → AI搭配
     ├→ AI搭配 → 搭配结果 → 我的搭配库 / OOTD发布
     ├→ 我的衣柜 / 闲置统计
     ├→ 穿搭广场 → OOTD发布
     └→ 个人中心 →（我的衣柜 / 闲置统计 / 我的搭配库 / 登录注册）

底部 Tab：首页 / 衣柜 / AI搭配（中间主按钮）/ 统计 / 我的
```

## 4. 关键功能需求详述（示例：AI 搭配生成）

**输入**

- 必选：场合（通勤/约会/面试/居家/旅行…单选）
- 可选：风格偏好（多选标签）比如"简约""甜酷""法式""运动"等标签
- **指定单品**（选填）：可以从衣柜里挑一件想穿的衣服，AI 围绕它来搭配
- **避开闲置单品**（选填）：一个开关，打开后 AI 不会推荐超过 90 天没穿的衣服
- 自动：根据用户所在城市自动获取，用户可以手动改

#### AI 生成后用户能看到什么

- **一套完整搭配**：包含外套、上衣、下装、鞋包，所有单品都来自用户自己的衣柜
- **适配度评分和推荐理由**：比如"这套搭配适合今天的天气，整体风格偏通勤，和你的衣柜契合度 85%"
- **单品备选列表**：每件单品旁边有个"换一件"按钮，点了可以换成同品类的其他衣服
- **多套备选方案**：除了主推的一套，还有 B 方案和 C 方案可以切换查看

### 4. 关键功能需求详述（示例：AI 搭配生成）

#### 用户在搭配页面需要填什么

- **场合**（必填）：从"通勤 / 约会 / 面试 / 居家 / 旅行"里选一个
- **风格偏好**（选填）：可以多选，比如"简约""甜酷""法式""运动"等标签
- **指定单品**（选填）：可以从衣柜里挑一件想穿的衣服，AI 围绕它来搭配
- **避开闲置单品**（选填）：一个开关，打开后 AI 不会推荐超过 90 天没穿的衣服
- **天气和气温**（自动带入）：根据用户所在城市自动获取，用户可以手动改

#### AI 生成后用户能看到什么

- **一套完整搭配**：包含外套、上衣、下装、鞋包，所有单品都来自用户自己的衣柜
- **适配度评分和推荐理由**：比如"这套搭配适合今天的天气，整体风格偏通勤，和你的衣柜契合度 85%"
- **单品备选列表**：每件单品旁边有个"换一件"按钮，点了可以换成同品类的其他衣服
- **多套备选方案**：除了主推的一套，还有 B 方案和 C 方案可以切换查看

#### 特殊情况怎么处理

- **衣柜里衣服太少（少于 3 件）**：不生成搭配，提示用户先去录入衣服
- **用户指定的单品和场合不搭**（比如选了睡衣但要面试）：给个提醒"这件可能不太适合面试场合哦"，但仍然可以生成
- **天气数据获取失败**（比如没网）：允许用户手动选择气温区间（如"15～20°C"）

**验收标准（原型层面）**

- ☑️ 点"生成搭配"后有个加载动画，不会让用户觉得卡死
- ☑️ 在结果页"换一件"后，单品清单的名字和图片会实时刷新
- ☑️ 点"保存搭配"后，去"我的搭配库"能看到刚才那套
- ☑️ 从搭配结果页点"分享"，能跳转到发布 OOTD 的页面，整条链路走通

## 5.我关心的用户行为（原型阶段定义）

| 事件      | 触发时机      | 关键属性             |
| ------- | --------- | ---------------- |
| 录入衣服    | 保存衣物到衣柜   | 来源(拍照/相册)、标签数、耗时 |
| 生成搭配    | 点击生成搭配    | 场合、风格数、是否指定单品    |
| 采用搭配    | 保存搭配/记录穿搭 | 适配度、替换次数、方案序号    |
| 换一件     | 单品"换一件"   | 被换品类（推荐质量负反馈信号）  |
| 闲置提醒    | 点击闲置提醒    | 闲置天数             |
| 处理闲置    | 挂闲置/预约捐赠  | 处理方式、估值          |
| 发布 OOTD | 发布 OOTD   | 话题数、是否 AI 文案     |

**北极星指标**：周搭配采纳次数（保存搭配 + 日历打卡）  
**激活定义**：新用户 7 日内录入 ≥ 5 件衣物
